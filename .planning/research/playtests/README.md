# Playtest logs
One file per session, named `YYYY-MM-DD-<what>.md` (e.g. `2026-10-21-phone-fps.md`): who played, on what device + browser, what they did, what they tripped on, numbers read (fps). A stage release (alpha / beta / 1.0) needs one dated since the last stage (release.mjs, F87). Muzzy's two-phone fps test (Sprint 11 task 8) is the first.
